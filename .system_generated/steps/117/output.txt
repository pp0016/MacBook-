1.  **Prioritize Direct Connections:** Tailscale defaults to direct peer-to-peer connections. If you find it is slow, use the `tailscale ping` command to check for packet loss and confirm you are not being routed through a distant DERP relay server.
2.  **Keep Clients Updated:** Always use the latest version of Tailscale on both your mobile device and the Ollama server host to benefit from the latest NAT traversal and performance optimizations.
3.  **Configure `OLLAMA_HOST`:** To make your Ollama instance accessible, set the environment variable `OLLAMA_HOST` to `0.0.0.0:11434` (or your specific Tailscale IP) on the host machine. This allows Ollama to listen on the Tailscale network interface.
4.  **Security:** Because you are exposing your Ollama instance to your private "tailnet," ensure you use Tailscale's built-in ACLs (Access Control Lists) to restrict access to only your authorized devices, rather than leaving the port open to the entire public internet.
5.  **Hardware Considerations:** Since you are using a mobile hotspot, ensure that the device running Ollama has sufficient compute (GPU) power. Tailscale will encrypt the traffic, which consumes a negligible amount of CPU, but the bulk of the "speed" will depend on the machine running the LLM inference.
